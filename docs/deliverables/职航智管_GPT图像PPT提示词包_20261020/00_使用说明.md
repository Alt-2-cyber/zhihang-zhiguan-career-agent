# 职航智管｜GPT 图像 PPT 提示词包

这是一套可直接复制的 **19 页整页图像提示词**，配有本次测试证据、**14 组产品截图、6 张细节裁切、9 张数据图和 6 张风格参考**。参考风格是《凌目智算》中的深蓝科技竞赛风；内容仍是职航智管，不迁移原作品的数字、人物或背书。

## 直接开始

1. 打开 [逐页提示词总稿](01_逐页提示词.md)，或打开 `逐页提示词/` 中对应页的 `.txt`。
2. 按该页“上传图片顺序”上传图片：第 1 张为风格参考，后面为本页截图或图表；路径均相对于本素材包。模型不能自行读取你的本地文件路径，需要实际上传附件。
3. 整段复制该页 `.txt`，发送给你使用的 GPT Image 2.5 图像生成界面。每页都已含完整母版说明，无需另拼总提示词。
4. 选择 16:9 横版及工具可用的最高分辨率；3200×1800 是版式目标，不是对具体模型分辨率或 API 名称的保证。
5. 建议先试 **P01 封面、P13 辅导员与数据、P15 测试结果**。三页分别检查整体风格、真实截图与图表，再继续其余页。
6. 生成后逐项核对数字、小字、数据图注与界面状态。图像模型若改写关键截图，可在 PowerPoint 中覆盖粘贴本包原图；总稿末尾也提供修正提示词。

## 包含什么

- [01_逐页提示词.md](01_逐页提示词.md)：19 页总稿、附件清单、同页修正提示词。
- [02_实测数据与截图说明.md](02_实测数据与截图说明.md)：测试结果、样本口径、未通过项和本次未验证的能力。
- `逐页提示词/`：19 个独立可复制 `.txt`。
- `截图/`：14 组真实页面与 6 张细节裁切。
- `图表/`：9 张 PNG，以及可编辑矢量 SVG。
- `风格参考/`：6 张参考原稿渲染图，仅用于视觉风格。
- `证据/`：汇总数据、可复核 CSV、用例、日志和哈希清单。
- [截图总览](截图总览.jpg)、[图表总览](图表总览.jpg)、[风格总览](风格参考总览.jpg)：快速选图。

## 先记住这些口径

24 名学生、85 条申请、96 项任务、9 条风险均来自**人工构造演示库**。岗位匹配与面试分数来自**本地规则演示**。后端 63/63、前端 25/25、API 22/22、风险边界 15/15 是本次验证结果；**现有浏览器回归仍有 5 项未通过**，已在第 15 页保留。

本包没有生成最终图片或 PPT，没有调用图像 API；它完成了参考分析、项目测试、真实截图和提示词准备。模型名称沿用你的称呼，不假定某个未核实的 API 型号标识。
