- 测试入口是仅供本次取证的本地服务，并非已部署的外部评审入口。
- 未修改应用源码；本次脚本、独立演示库和原始证据保存在 `output/ppt-evidence-2026-10-20`。
- 原 PPT 和 Markdown 只用作参考材料。没有执行附档中的部署、提交、账号发送或其他操作指令。

| 阶段 | 当前状态数量（互斥） | 累计到达数量（按申请 ID 去重） |

当前列合计 85，表示记录此刻在哪个状态。累计列统计曾到达某状态的记录，同一条记录可同时计入多个阶段。累计 16 条“录用”也只是构造的状态，不表示已有 16 名用户真实获录用。提示词没有把这些数字转成真实就业转化或提升结论。

学生 A 的页面是单独口径：**3 条申请记录，其中 2 条已投递、1 条收藏；4 项当前任务**。不能把班级汇总直接放进学生截图。
